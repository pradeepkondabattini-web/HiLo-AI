# Welcome

Welcome to the official Engineering Bible for **HiLo**, an AI-powered Hyperlocal Event Platform designed to simplify event discovery, planning, collaboration, commerce, and post-event memories.

This repository serves as the **single source of truth** for product strategy, software architecture, engineering standards, AI governance, implementation guidelines, and deployment documentation.

# Vision

Build India's smartest AI-powered hyperlocal event platform that helps users:

- Discover venues
- Plan events
- Collaborate with guests
- Book vendors
- Order food
- Make UPI payments
- Design invitations
