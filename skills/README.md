# skills/

Versioned AI **Skill** definitions — reusable, deterministic business capabilities
executed via the Skill Registry (EOS-000 §100–101, Book 05 EOS-005-P5).

Each Skill declares: id, version, owner, description, input schema, output schema,
permissions, dependencies, tests, and documentation. Skills may call APIs, query
Firestore, or invoke MCP tools; they never touch UI and remain platform-independent.

Populated from **Sprint 4** onward.
